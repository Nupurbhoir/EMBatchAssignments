✨ Project Overview

This project demonstrates how to build a professional profile screen using fundamental Flutter layout and UI widgets.

The screen adapts automatically to different screen sizes:

🖥️ Desktop — two-column dashboard layout

💻 Tablet — responsive card arrangement

📱 Mobile — vertically stacked profile sections

The design uses a solid-color visual system with pink, sky blue, black and white instead of gradients.

The asset is declared in pubspec.yaml:

flutter:
  uses-material-design: true

🚀 Getting Started

1. Clone the repository

git clone https://github.com/Nupurbhoir/profile-card-flutter.git
cd profile-card-flutter

2. Install dependencies

flutter pub get

3. Format the project

dart format lib/main.dart

4. Analyze the project

flutter analyze

5. Run tests

flutter test

6. Run the application

flutter run -d chrome
